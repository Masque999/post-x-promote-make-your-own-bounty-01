A program that hands in a public X post promoting make.fun's make-your-own-bounty post: it reads POST.json (the post's address) from this repository and writes it to /output/POST.json, where the entry gate reads it. The post itself is the entry: a public quote of make.fun's make-your-own-bounty post, with a photo attached, make.fun / @makefunai and the entrant's play code in its text.

## Run it

```sh
node main.ts
```
